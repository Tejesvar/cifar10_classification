# CIFAR-10 Image Classification

## 🧠 Overview
This project builds a Convolutional Neural Network (CNN) using TensorFlow to classify images from the CIFAR-10 dataset into 10 categories such as airplanes, cars, birds, and more.

## 🛠️ Tools & Technologies
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

## 📊 Model Summary
- CNN architecture with Conv2D, MaxPooling, and Dense layers
- Trained on 50,000 images, validated on 10,000
- Achieved ~70% accuracy (update with your actual result)

## 📁 Files
- `cifar_image_recognition.ipynb`: Main notebook with model building, training, and evaluation
- `README.md`: Project summary and instructions

## 🚀 How to Run
1. Clone the repo
2. Install dependencies: `pip install tensorflow numpy matplotlib`
3. Open `cifar_image_recognition.ipynb` in Jupyter Notebook
4. Run cells sequentially to train and evaluate the model

## 📌 Use Case
Useful for beginners exploring image classification and CNNs. Can be extended to real-world applications like object detection or medical imaging.
